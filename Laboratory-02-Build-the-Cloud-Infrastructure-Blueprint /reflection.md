Mission Reflection
1. Which cloud infrastructure component do you think is the most important? Why?

For me, the network is the most important cloud infrastructure component because it connects the different parts of the system. A compute resource can run applications and storage can hold data, but they still need a network to communicate with each other and with users. This laboratory helped me understand that cloud infrastructure is not just about servers; the components need to work together.

2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable environment for running servers, applications, and cloud workloads. During this laboratory, I used the KillerCoda Linux terminal to inspect the operating system, kernel, CPU, storage, hostname, and IP address. Commands such as uname, lscpu, lsblk, and hostname helped me understand the resources available on the server.

3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it gives engineers a clear record of what has been investigated and planned before deployment. It also helps other people understand the infrastructure and can prevent mistakes. During this activity, I realized that a good diagram and organized documentation can make a technical system much easier to understand.

4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux cloud environment using command-line tools and identify compute, storage, networking, and operating-system resources. I also practiced creating a simple cloud infrastructure diagram, writing Markdown documentation, and organizing files in a GitHub repository. These are practical skills I can use in future cloud computing activities.

5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio became more organized and meaningful because I added a complete laboratory project with documentation, investigation results, screenshots, and a cloud architecture diagram. Instead of only having basic files, the portfolio now shows my process and what I learned. This makes it a better record of my progress as I continue learning cloud computing.
