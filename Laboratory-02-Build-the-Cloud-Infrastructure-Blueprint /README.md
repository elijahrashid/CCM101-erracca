# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

The mission of this laboratory is to design and document a simple cloud infrastructure blueprint for a fictional company. The laboratory focuses on understanding the basic components of cloud infrastructure and how users connect to cloud-based computing and storage resources through a network.

The project demonstrates a simplified cloud environment consisting of a user, an Internet connection, a virtual network, a compute resource, and a storage resource.

## Objectives

The objectives of this laboratory are to:

* Understand the basic components of cloud infrastructure.
* Design a simple cloud architecture diagram.
* Identify the roles of compute, storage, and networking resources.
* Demonstrate how a user accesses cloud resources through the Internet.
* Practice using Linux commands and basic command-line operations.
* Document the laboratory activities using Markdown.
* Develop foundational cloud infrastructure and technical documentation skills.

## Cloud Infrastructure Components

The cloud infrastructure blueprint contains the following components:

| Component               | Description                                                                            |
| ----------------------- | -------------------------------------------------------------------------------------- |
| **User**                | Represents the person accessing the cloud infrastructure using a computer or laptop.   |
| **Internet Connection** | Provides connectivity between the user and the cloud environment.                      |
| **Network**             | Represents the virtual network that connects and organizes the cloud resources.        |
| **Compute Resource**    | Represents a virtual machine used to run applications or workloads.                    |
| **Storage Resource**    | Represents cloud storage used to store files, application data, and other information. |

### Architecture Flow

The basic infrastructure follows this flow:

```text
User
  |
  v
Internet
  |
  v
Virtual Network
  |
  +------------------+
  |                  |
  v                  v
Compute Resource   Storage Resource
(Virtual Machine)  (Object Storage)
```

The user connects to the cloud environment through the Internet. The virtual network provides connectivity between the compute and storage resources.

## Challenges Encountered

One of the main challenges was understanding how the individual cloud infrastructure components are connected and how they work together as a complete system.

Another challenge was creating a simple architecture that clearly represents the required components without adding unnecessary resources. The diagram needed to include exactly the fundamental elements required for the laboratory: a user, Internet connection, network, compute resource, and storage resource.

Working with Linux commands and Git also required attention to directory locations, file names, repository status, and commit operations.

These challenges helped improve familiarity with cloud architecture, command-line operations, version control, and technical documentation.

## Conclusion

This laboratory provided a practical introduction to designing a basic cloud infrastructure blueprint. The completed architecture demonstrates how a user can connect through the Internet to a virtual cloud network containing compute and storage resources.

The laboratory also strengthened foundational skills in Linux, Git, GitHub, cloud infrastructure, diagramming, and Markdown documentation.
