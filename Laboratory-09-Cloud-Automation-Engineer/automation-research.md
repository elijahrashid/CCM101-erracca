# Checkpoint 2 - Research: The Language of Automation

## 1. Bash Script

A Bash script is a file that contains a series of Linux commands that can be executed automatically in sequence. The `#!/bin/bash` line, called the shebang, tells the operating system to use the Bash interpreter to run the script.

## 2. Variables

Variables are used to store values, such as folder paths or filenames, so they can be reused throughout a script. For example, using `$BACKUP_DIR` makes it easier to change the backup location in one place instead of editing every command that uses the same path.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs a command or script automatically at a specified time or interval. It is essential in cloud operations because it helps automate repetitive tasks, such as backups and system maintenance, reducing manual work and the chance of human error.
