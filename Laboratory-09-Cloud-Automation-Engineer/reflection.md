
# Mission 9: Mission Reflection

## 1. Why is automation critical when managing hundreds of cloud servers?

Automation is important when managing hundreds of cloud servers because performing every task manually takes too much time and can lead to mistakes. Scripts can perform repetitive tasks, such as backups and system maintenance, more consistently. This allows administrators to manage many servers efficiently and focus on other important responsibilities.

## 2. What are the potential dangers of automation?

Automation can cause serious problems if a script contains an error or a destructive command. For example, if a script with a typo runs on 1,000 servers, it could delete important files or interrupt services across the entire environment. To reduce these risks, scripts should be tested carefully, reviewed before deployment, and monitored after execution.

## 3. How did writing a Bash script differ from creating a Docker Compose YAML file in Mission 6?

Writing a Bash script involved creating a sequence of commands that perform tasks such as creating directories and compressing files. Docker Compose YAML, on the other hand, describes how services and containers should be configured and connected. Both tools help automate work, but Bash focuses on executing commands while Docker Compose manages application services.
