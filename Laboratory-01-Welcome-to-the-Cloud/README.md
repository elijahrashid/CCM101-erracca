# Laboratory Activity 1 – Mission 1: Welcome to the Cloud

## Mission Overview
Onboarding mission as a Junior Cloud Infrastructure Engineer Trainee — learning to navigate Linux, document work, and build a version-controlled GitHub portfolio.

## Objectives
- Access a cloud-based Linux environment using KillerCoda
- Explore and navigate the Linux OS
- Gather basic system information
- Organize files and directories using Linux commands
- Create a professional GitHub repository
- Document technical work using Markdown

## Activities Performed
1. Launched KillerCoda Ubuntu playground and created a sudo user (erracca)
2. Investigated system info (distro, kernel, CPU, memory, disk)
3. Built folder structure: Documents, Notes, Reports, Screenshots
4. Created and viewed about-me.md
5. Set up GitHub portfolio repository with proper structure

## Linux Commands Used
- `whoami`, `pwd`, `hostname`
- `sudo adduser`, `usermod -aG sudo`, `su`
- `lsb_release -a`, `uname -r`, `lscpu`, `free -h`, `df -h`
- `mkdir`, `ls`, `nano`, `cat`

## Skills Learned
Gained hands-on experience navigating a Linux environment, managing users and permissions, inspecting system resources, organizing a file system, and documenting technical work using Markdown — foundational skills for cloud infrastructure engineering.
