
# Mission 8: Mission Reflection

## 1. How does a host-based firewall protect a server even if the physical network perimeter is breached?

A host-based firewall protects an individual server by controlling the network traffic that can enter or leave it. Even if an attacker passes through the network's main security defenses, the firewall can still block unauthorized connections based on its rules. This provides another layer of protection for the server.

## 2. Why is managing open network ports critical to reducing a server's attack surface?

Managing open ports is important because every unnecessary open port can provide another possible entry point for attackers. Closing unused ports and allowing only required services reduces the opportunities for unauthorized access. This makes the server more secure and easier to manage.

## 3. Why is it dangerous to leave a database port like 3306 for MySQL open to the public internet?

Leaving MySQL port 3306 open to the public internet can expose a database to unauthorized access, password attacks, and attempts to exploit vulnerabilities. If an attacker gains access, sensitive information could be stolen, modified, or deleted. Database access should be restricted to trusted servers and users that actually need it.

## 4. How did completing this mission change your perspective on how easily a server can be compromised?

This mission helped me understand that a server can become vulnerable when security settings are not configured properly. Even a simple web application can be exposed if unnecessary ports are open or firewall rules are missing. I learned that securing a server requires careful configuration, regular checking, and continuous monitoring.
