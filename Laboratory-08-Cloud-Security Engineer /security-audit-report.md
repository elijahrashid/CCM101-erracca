# Checkpoint 2 - Research: Security Best Practices

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means that each user should only have the permissions needed to perform their assigned tasks. It is important for cloud user accounts because it helps prevent unauthorized access and reduces the damage that could happen if an account is compromised.

## 2. Attack Surface

The attack surface of a virtual machine refers to all the possible points where an attacker could try to gain access or exploit a weakness. Examples include open ports, running services, outdated software, and weak passwords. Reducing unnecessary services and closing unused ports can help make the virtual machine more secure.

## 3. Default Deny Policy

A Default Deny Policy means that all incoming or outgoing traffic is blocked unless it is explicitly allowed by a security rule. This is safer than trying to block individual hackers because new or unknown threats may still get through if they are not on the blocklist. Allowing only trusted and necessary traffic reduces the chances of unauthorized access.
