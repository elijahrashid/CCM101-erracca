## Analysis Questions

**1. Which cloud provider offers the broadest range of services?**
AWS offers the broadest range of services, with over 200 distinct offerings covering nearly every category of cloud computing. This breadth comes from being the first major provider and having the longest time to build out its catalog. As a result, AWS is often the default choice when a business needs a highly specific or niche service.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure best integrates with Microsoft technologies, since it is built by the same company that develops Windows Server, Active Directory, and Microsoft 365. Organizations already running these on-premises can extend them into Azure with minimal friction using tools like Azure AD Connect and Azure Arc. This makes Azure the natural choice for enterprises with an existing Microsoft-centric IT environment.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform is strongest in both AI and Kubernetes. GCP created Kubernetes internally before open-sourcing it, so its managed Kubernetes service (GKE) is widely regarded as the most mature. GCP also leads in AI/ML tooling through services like Vertex AI and BigQuery ML, which are deeply integrated with Google's own research in machine learning.
