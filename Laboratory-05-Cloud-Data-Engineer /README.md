# Laboratory 05 — Cloud Data Engineer

## Mission Overview
This activity simulates being assigned to the Cloud Data Engineering Team at CloudNova Technologies to build a proof-of-concept Object Storage environment for a client's photo-sharing application. The task was to deploy an S3-compatible object storage server, create a secure bucket, and upload a test file to prove the system works.

## Objectives
- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible Object Storage server (MinIO) using Docker.
- Access a cloud service via a web interface using port forwarding.
- Create a storage bucket and upload objects to the cloud.
- Document cloud storage operations using Markdown.
- Continue expanding a professional GitHub Cloud Computing Portfolio.

## Tools Used
- Docker
- MinIO (via the `pgsty/minio` community-maintained image)
- KillerCoda Ubuntu Playground
- Markdown
- GitHub

## Skills Learned
- Deploying a containerized service with environment variables to configure it at startup.
- Distinguishing Block, File, and Object Storage and when each is appropriate.
- Accessing a service running inside a remote container through port forwarding.
- Creating and using an S3-compatible storage bucket through a web console.
- Diagnosing and working around a broken/deprecated Docker image by finding a maintained alternative.
- Writing clear technical documentation in Markdown.
